🚀 3-STEP INSTALLATION (Most People):

  1. HOST THE FILES
     Choose ONE option:
     
     A) GitHub Pages (FREE & EASIEST)
        • github.com → Create free account
        • Create new public repo "tomten"  
        • Upload 5 files
        • Settings → Pages → Enable
        • URL: https://username.github.io/tomten
     
     B) Web Host (Your own server)
        • Upload 5 files to your web server
        • Get the URL: https://example.com/tomten
     
     C) Local Network (Testing)
        • Save 5 files in one folder
        • Command: python -m http.server 8000
        • Find your IP: ipconfig (Windows) or ifconfig (Mac)
        • URL: http://192.168.X.X:8000

  2. OPEN ON iPHONE
     • Safari → Go to URL from step 1
     • Tap Share (⬆️ button)
     • Scroll → "Add to Home Screen"
     • Tap "Add"

  3. DONE!
     ✓ Icon on home screen
     ✓ Works offline after first visit
     ✓ Plays on any iPhone (iOS 11.3+)

❓ COMMON QUESTIONS:

  Q: Will it work offline?
  A: YES! After first visit with internet, works forever offline.

  Q: How much space does it use?
  A: ~2 MB on phone. Game files only ~50 KB.

  Q: Can I share it with others?
  A: YES! Just share the URL. They add to their home screen.

  Q: Do they need internet?
  A: NO! After they visit once, it caches and works offline.

  Q: Can I update the game?
  A: YES! Update files on server, next visit gets latest version.

⚡ IF SOMETHING DOESN'T WORK:

  App won't install?
  → Try different browser (Chrome, Firefox)
  → Check iOS version (need 11.3+)
  → Refresh page first

  Blank screen?
  → Hard refresh: Cmd+Shift+R (Mac) or Ctrl+Shift+R (Windows)
  → Or close app completely and reopen
  
  Not working offline?
  → First visit MUST have internet (to cache files)
  → Close app completely, reopen
  → Ensure 5+ MB free storage
