## 🎮 Game Files (What to Upload)

These 5 files work together to create the complete offline game:

```
✓ index.html       - The complete game (HTML + CSS + JavaScript)
✓ manifest.json    - Tells browsers/phones how to display the app
✓ sw.js            - Service Worker (enables offline functionality)
✓ icon-192.svg     - App icon for small devices (phone, tablet)
✓ icon-512.svg     - App icon for large displays
```

**All 5 files must be uploaded together to the same location.**

## 📱 iPhone Installation (Quick Version)

1. **Get the URL** (from hosting: GitHub Pages or Web Host)
2. **Open Safari** on iPhone
3. **Go to URL**
4. **Share → Add to Home Screen**
5. **Tap "Add"**
6. ✅ **Done!** Icon on home screen, works offline
